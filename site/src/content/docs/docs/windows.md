title: Windows

---

ShapeLogic installs on Windows with a standard `.exe` installer. This page
covers running the installer and where to find the command line tool.

## Running the installer

Download the `.exe` from the
[latest release](https://github.com/shapelogicxyz/shapelogic/releases/latest)
and run it.

The installer is not code-signed yet, so Windows SmartScreen may say it
protected your PC. Choose **More info**, then **Run anyway**.

The installer asks whether to install for you only or for everyone on the
computer, and lets you choose the folder.

## Puzzle files

ShapeLogic registers itself for `.xmpuzzle` puzzle files and `.slsolve` paused
solves, so double-clicking one in File Explorer opens it in ShapeLogic.

## The command line tool

`shapelogic_cli.exe` is installed with the app. Choose
**Help ▸ Command Line Tool…** to see where it is. See
[Command Line Tool](/docs/command-line/#getting-the-tool).
