# The puzzles of the regression suite (regress.py), relative to the
# repository. Every one is a file of this repository: the suite reads and
# runs nothing else.
#
# Columns: tier  flags  path-or-glob
#   tier  fast      every run (seconds in total)
#         full      before finishing a solver change (about ten seconds)
#         slow      benchmarks and final checks (seconds each)
#         sliding   the sliding puzzles: run with --tier sliding
#         stacking  the stacking puzzles: run with --tier stacking, and
#                   --solver panex for the Panex Solver
#   flags "-" none
#         "R" the take-apart with rotations (-R)
#         "A" a grid the original could not take apart (spheres, rhombic,
#             tetra-octa): the text runs assemble only
#         "D" (with "A") the new core takes it apart all the same, with
#             movement checks derived from the cells (decision 0025): its
#             summary answer is ShapeLogic's
#         "N" sliding: --nested-slides; "P" sliding: --partial-nested
#         "O" sliding: several starts. A shorter path to a picture already
#             counted counts again, so on several threads the counts depend
#             on the order the starts come in: compared with --threads 1 only
#         "Q" stacking: not for the Panex Solver (no Panex columns, or more
#             rods than it holds)
#         "L" stacking: its further problems run for hours: no -o all run
#         "C" not run with --solver crowell: its take-apart does not end
#             (the original's ran for an hour and was stopped)
#
# The files under tests/data/puzzles/regression/ are named by what they
# test. Never add the commercial sliding puzzle "One Way or Another".
