## Commits

Never commit, amend, rebase, switch branches or push unless the user asks
for it in the conversation: the user tests and tweaks the work first, on
every branch. Where AGENTS.md says a stage ends with "one commit", that
means the work is left ready to commit, in the working tree, with a note
of what is in it and the commit message it would get.

## Spelling

Write American English everywhere: code, identifiers, comments, docs, the
website and the research pages (color, center, neighbor, gray, canceled).
The web unit test `spelling.test.ts` fails on a British spelling; a line that
must keep one (a name an older version saved) ends with `// british-ok`.
