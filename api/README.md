# Engine API schema

The JSON Schema of every `bt-engine` method and event (decisions 0003 and
0012). It is the single source for:

- `docs/API.md`, the reference, generated by `gen_api_md.py` (a test fails
  when it is stale: run `python3 api/gen_api_md.py` after editing);
- the engine's contract tests (`tests/contract/`), which check every reply
  and event against it and that the engine's methods are the schema's;
- the TypeScript types of the web front end (later).

## Files

| File | Holds |
|---|---|
| `types.json` | the shared definitions (`$defs`): ids, enums, the items |
| `engine.json` | `engine.*`, `settings.*`, the `frame` announcement |
| `document.json` | `document.*`, `edit.*`, `document.changed` |
| `shape.json` | `shape.*`, `grid.geometry` |
| `colour.json` | `colour.*` |
| `problem.json` | `problem.*` |
| `solve.json` | `solve.*` and its events |
| `solution.json` | `solution.*` and the analysis events |
| `playback.json` | `playback.*` |
| `explore.json` | `explore.*` |
| `apischema.py` | loads the files, checks them, validates messages |
| `gen_api_md.py` | writes `docs/API.md` |

An area file is
`{"$schema", "$id", "title", "description", "methods": {name: {"summary",
"params", "result", "errors"}}, "events": {name: {"summary", "params"}},
"$defs"}`; `params`, `result` and the `$defs` are JSON Schema 2020-12.

## The subset

Only these keywords are used, so that `apischema.py` (no packages needed)
checks all of them: `type`, `properties`, `required`,
`additionalProperties`, `items`, `enum`, `const`, `pattern`, `minimum`,
`maximum`, `minItems`, `maxItems`, `minLength`, `oneOf`, `$ref` (`#/...` or
`other.json#/...`), and the annotations `title`, `description`. Run
`python3 api/apischema.py` to check the schema: a keyword outside the
subset, a `$ref` that does not resolve or an entry without summary, params
or result is reported.

## Adding a method

1. Its entry in the area's file (params with `additionalProperties: false`;
   the engine refuses unknown params too).
2. The handler in `engine/methods_<area>.cpp`, registered in its
   `add…Methods`.
3. A call in `tests/contract/test_engine.py` (the coverage check fails for
   a method never called with success).
4. `python3 api/gen_api_md.py`.
