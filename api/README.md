# Engine API schema

From stage 7 this folder holds the JSON Schema of every `bt-engine` method
and event (decision 0003). It is the single source for:

- `docs/API.md` (generated reference),
- the TypeScript types the web front end imports,
- the engine's contract tests.

Until then, the planned operations are listed in
[docs/core-api.md](../docs/core-api.md).
